# Asociación Civil de Plomeros y Sanitaristas de Corrientes

Este repositorio contiene el sitio web institucional de la Asociación. Lo hice como un sitio estático para que sea simple de mantener y pueda publicarse directamente con GitHub Pages.

**Sitio publicado:**  
https://asociaciondeplomerosysanitaristas-corrientes.site

## Qué tiene

- página de inicio;
- información sobre la Asociación;
- sección de eventos;
- formulario de contacto;
- enlaces a redes sociales;
- diseño adaptable para computadora y celular.

## Tecnologías

- HTML
- CSS
- JavaScript
- GitHub Pages
- FormSubmit para el formulario de contacto

GitHub Pages se encarga de publicar el sitio y el dominio personalizado apunta directamente a esa publicación. El formulario usa FormSubmit porque GitHub Pages no ejecuta PHP.

## Archivos principales

`index.html` contiene la página de inicio.  
`quienes.html` reúne la información institucional.  
`eventos.html` contiene las actividades y eventos.  
`contacto.html` tiene el formulario de contacto.  
`css/` guarda los estilos de cada página.  
`imagen/` contiene el logo, fotos e íconos usados en el sitio.
