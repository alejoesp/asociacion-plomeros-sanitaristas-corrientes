# Asociación Civil de Plomeros y Sanitaristas de Corrientes

Este repositorio contiene el sitio web institucional de la Asociación. Lo hice como un sitio estático para que sea simple de mantener y pueda publicarse directamente con GitHub Pages.

**Sitio publicado:**  
https://asociaciondeplomerosysanitaristas-corrientes.site

## Secciones

- Inicio
- Quiénes somos
- Eventos
- Contacto

## Tecnologías

| Parte | Herramientas |
| --- | --- |
| Estructura | HTML |
| Estilos | CSS |
| Interacciones | JavaScript |
| Publicación | GitHub Pages |
| Formulario | FormSubmit |
| Dominio | Dominio propio + HTTPS |

GitHub Pages publica el sitio directamente desde la rama principal. El formulario utiliza FormSubmit porque GitHub Pages no ejecuta PHP.

## Archivos principales

`index.html` contiene la página de inicio.  
`quienes.html` reúne la información institucional.  
`eventos.html` contiene las actividades y eventos.  
`contacto.html` tiene el formulario de contacto.  
`css/` guarda los estilos de cada página.  
`imagen/` contiene el logo, fotos e íconos usados por el sitio.

La configuración del dominio se mantiene con el archivo `CNAME`.
